# Assets visuels

Les visuels de la V1 ont été optimisés à partir des maquettes Full Impact fournies avec le projet de création du site. Ils sont temporaires et remplaçables sans changer l'architecture.

- `hero-impact.webp` : visuel principal de l'accueil
- `problem-impact.webp` : visuel de la page Problème
- `solution-product.webp` : bouclier + application de la page Solution
- `full-impact-mark.png` : marque temporaire utilisée dans le header/footer
- `og-full-impact.webp` : aperçu pour partage social
